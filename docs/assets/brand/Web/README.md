# Website starter files

`brand.css` is scoped to `<body class="brand-site">`. Use `data-theme="light"`
or `data-theme="dark"` on `<html>` for an explicit choice; otherwise the CSS
follows system preference. It is an implementation starting point, not an
already-tested replacement website. Merge it after inspecting existing CSS.

Keep Fonts alongside Web so relative font paths work. Use the app-specific
WEBSITE-REVAMP.md for page structure and exact content/anchor preservation.
The CSS does not implement theme-button behavior or replace the existing TOC
script. Implement and test these interactions in the target repository.
